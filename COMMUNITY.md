# Community

## Public communication

GitHub Issues and pull requests are Ayni's public channels for bug reports,
feature proposals, design discussion, and contribution review. Significant
decisions are recorded there so contributors can follow and participate.

The project currently has no regular public meeting and no private contributor
chat. If either is introduced, this document will list its purpose, access
rules, and archival expectations.

## Private channels

Private security reports use the process in [SECURITY.md](SECURITY.md). Private
channels must not be used for ordinary product, roadmap, or governance
decisions; those belong in the public channels above.
